SUMMIT OUTDOOR GEAR
Business Central Implementation Practice Project
================================================

This package contains everything you need to practice a functional Business Central implementation on your own.

CONTENTS
--------
1. Summit_Outdoor_BC_Implementation_Guide.docx
   - Complete project guide covering company background, scope, configuration checklist,
     master data instructions, end-to-end practice scenarios, testing, and a suggested roadmap.

2. Data/ folder with Excel files ready for import or manual entry:
   - Chart_of_Accounts.xlsx
   - Customers.xlsx
   - Vendors.xlsx
   - Items.xlsx
   - Locations.xlsx
   - Payment_Terms.xlsx

HOW TO USE
----------
1. Provision a Business Central sandbox or trial environment.
2. Read the Implementation Guide thoroughly.
3. Follow the Configuration Checklist (especially Posting Groups) before loading data.
4. Import the Excel data using Configuration Packages, or enter it manually.
5. Execute the practice scenarios in the guide and document your observations.
6. Review reports (Trial Balance, Inventory Valuation, Aged AR/AP) to validate results.

TIPS FOR TECHNICAL PROFESSIONALS
---------------------------------
- Pay attention to how Posting Groups drive G/L entries — this is the bridge between functional design and the data model you already know.
- Experiment with reversing documents and observe the Item Ledger and G/L entries.
- Try changing the costing method or location setup and see the impact on inventory valuation.
- Use the Configuration Package feature to practice real data migration techniques.

This is a self-contained practice environment. Feel free to extend the company data, add more complex scenarios, or introduce additional modules as you grow more comfortable with the functional side of Business Central.

Happy practicing!
